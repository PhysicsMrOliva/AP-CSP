From wave to bits

Everything you see and hear changes smoothly. A computer can only store a finite list of 0s and 1s. In this lesson you’ll take a sound apart the way a computer does: sample it, round it, encode it, then listen to what survived.

1

Analog vs. digital

The real world is analog. Sound, light, and temperature change smoothly, and between any two moments there’s always another moment with its own exact value. Zoom in on a sound wave as far as you like and there is still more detail.

A computer can’t store infinite detail. It stores digital data: a finite list of values, each written in binary. You already know how numbers and text become binary. This lesson tackles the harder problem: turning a continuous signal, like your voice, into bits.

Sort these

Decide whether each one is analog (smooth, continuous) or digital (a finite set of stored values).

Key idea

Analog data changes smoothly and has infinite detail. Digital data is a finite set of separate values stored in binary, so a digital version of anything analog is always an approximation.

2

Sampling

The first step is to measure the signal at regular time intervals. Each measurement is a sample. The time between samples is the sampling interval, and the number of samples per second is the sampling rate.

When sampling goes wrong: aliasing

Sample too slowly and a fast signal can look like a slower one that was never there. That’s aliasing, the same effect that makes car wheels seem to spin backward in videos. The Nyquist–Shannon sampling theorem says the sampling rate must be greater than twice the highest frequency in the signal. Frequency is cycles per second, measured in hertz (Hz).

This wave repeats 5 times per second (5 Hz). Slide the sampling rate down and watch what the computer “sees.”

Real 5 Hz signal Samples The slowest wave that fits the samples
Key idea

Sampling turns a continuous stream into a finite list of measurements. Music is usually recorded at 44,100 or 48,000 samples per second, just over twice the roughly 20,000 Hz limit of human hearing. Phone calls use 8,000, since speech mostly stays below 4,000 Hz.

3

Quantization

After sampling we have a finite number of samples, but each one could still be any value, like 47.8291824806 volts. Quantization rounds every sample to the nearest of a fixed set of levels. The number of bits used to store each sample is the bit depth. With n bits you get 2n levels.

The difference between the real value and the rounded value is the quantization error. Every sample also has to fit inside the converter’s range, here −100 to 100 volts.

Fill in the table: how many levels (separate values) can each bit depth represent? Press Enter after each one to check it.

Key idea

Quantization rounds each sample to one of 2n levels. More bits per sample means more levels, which means less quantization error. Anything outside the range gets clipped, and that detail is gone for good.

4

Binary encoding

Once every sample sits on one of a fixed set of levels, the computer doesn’t need to store voltages at all. It numbers the levels 0, 1, 2… and stores each sample’s level number in binary. With 3 bits per sample there are 8 levels, numbered 0 through 7, which is 000 through 111.

Your turn: read each sample’s level from the graph and type it as a 3-bit binary number.

Here’s the whole recording as the computer stores it: 8 samples × 3 bits = 24 bits.

Key idea

Encoding stores each sample’s level as an n-bit binary number. The file also has to record how it was made (the sampling rate and bit depth) or the bits can’t be turned back into sound.

6

The cost of quality

Every improvement in quality costs storage space. For uncompressed audio:

bits = sampling rate × bit depth × channels × seconds

Stereo sound has 2 channels (left and right). Divide bits by 8 to get bytes.

Key idea

The goal is to sample with enough detail to rebuild the signal at the quality you need without running out of space. Landline phones use low sampling rates and bit depths because the data travels over limited lines. Film studios record at very high settings so it holds up on a giant screen.
